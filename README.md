# Typhoon Watch / 台风追踪站

这是一个无需后端的单页台风追踪网站。

## 数据源
- 日本气象厅 JMA：活动台风列表与详细预报
- 国土地理院：底图

## 使用
直接部署 `index.html` 到任意静态网站托管即可。

本地预览建议：
```bash
python -m http.server 8000
```
然后浏览器打开：
`http://localhost:8000`

## 功能
- 自动读取 JMA 当前发布中的台风/热带低气压
- 中心位置、气压、最大风速、移动方向与速度
- 未来预报节点与预报圆
- 强风域/暴风域可视化
- 每 10 分钟自动刷新
- 响应式桌面/手机布局

> 防灾决策请以 JMA 及当地政府发布的正式警报为准。
